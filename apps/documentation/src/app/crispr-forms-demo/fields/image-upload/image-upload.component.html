Processing state

While an image is being compressed the field reports a 'processing' state and the form is invalid. Use 'processingStateChange' to react to every transition ('idle', 'processing', 'failed'). The form also exposes the aggregate of all its image fields as a 'processingState' signal and a 'processingStateChange' output, so a Save button outside the form can follow it without wiring a callback into every image field's config.

Compression timeout

'compressionTimeoutMs' (default 30000, 0 disables) is how long a selected image may take to process before the field gives up. This field uses 1 ms, so selecting an image that needs compression fails with a 'took too long' message. Smaller images are not compressed and still work.

Initial value

The preview shows the initial value until a new image is selected, and never again once the control is cleared.
